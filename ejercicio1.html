La tienda de ropa de Ana

De las ventas a mejores decisiones

🛍️

El reto de Ana

¿Cómo saber qué prendas comprar?

Ana tiene una pequeña cadena de tiendas de ropa y quiere saber qué prendas se venden más para comprar solo lo necesario y reducir costes. Para ello, ha empezado a registrar las ventas de cada caja registradora en una hoja de cálculo.

De principio a fin

El viaje de los datos

7 momentos · 1 ciclo completo

🧭 CASO A

Planificar

Ana decide que va a medir las ventas por talla, color y precio unitario, asignando a su dependienta Carla la responsabilidad de revisar los datos cada semana.

Fase

Planificar

Justificación: En esta fase se define qué información necesita el negocio y quién se encargará de revisarla.

📥 CASO B

Capturar

Al terminar el día, el escáner de código de barras de la caja envía automáticamente los números de cada prenda vendida al sistema.

Fase

Capturar / recopilar

Justificación: El escáner obtiene los datos de cada venta y los incorpora al sistema para que puedan utilizarse.

☁️ CASO C

Almacenar

Ana guarda la base de datos de todo el año en un servidor seguro en la nube con copias de respaldo.

Fase

Almacenar / organizar

Justificación: La información se conserva de forma segura y organizada para poder consultarla más adelante.

🧹 CASO D

Procesar

El sistema detecta tres ventas en las que no se anotó la talla de la camisa y corrige esos campos vacíos para que no fallen los cálculos.

Fase

Procesar / transformar

Justificación: El sistema revisa y corrige datos incompletos para mejorar su calidad y evitar errores en los cálculos posteriores.

📈 CASO E

Analizar

Ana calcula cuál es la prenda que deja más margen de ganancia neta por mes.

Fase

Analizar / usar

Justificación: Ana compara los resultados de las ventas para obtener conclusiones sobre la rentabilidad de cada prenda.

💬 CASO F

Compartir

Ana crea un gráfico de barras colorido en la pantalla de su portátil para enseñárselo a su socio.

Fase

Compartir / visualizar

Justificación: El gráfico representa los resultados visualmente y permite compartirlos con su socio de forma clara.

♻️ CASO G

Destruir

Tras guardar durante 5 años registros antiguos que ya no necesita por ley fiscal, Ana borra permanentemente esos archivos del disco duro.

Fase

Archivar / destruir

Acción concreta: destruir

Justificación: Una vez cumplido el plazo de conservación, Ana elimina los archivos de forma permanente porque ya no es necesario guardarlos.

✨ Un ciclo completo: los datos se planifican, se cuidan y se convierten en conocimiento útil.
